# Conversão de página

Analise a primeira impressão: ícone, primeira captura, headline, clareza da
promessa, correspondência com o app, avaliação pública e atrito de instalação.
Mostre interface real; arte conceitual deve ser claramente marcada como tal.

Cada experimento contém: hipótese, controle, única variável, métrica principal,
métrica de proteção, segmento, duração/volume definido pelo console, critério
de decisão e condição de parada. Apple P.P.O. e Google Store Listing
Experiments são instrumentos diferentes; não replique parâmetros sem conferir
as capacidades atuais.

Carregue `aso-store-listing` para redigir os campos e `appstore-publishing` ou
`playstore-publishing` para os limites da loja.
