# Estratégia de release

Monte plano 30/60/90 dias com situação inicial, objetivo mensurável, hipóteses,
ações, experimento, responsável, indicador, critério de sucesso e de parada.
Separe manutenção de lançamento com hipótese comercial nova.

Uma rotina periódica é uma instrução executável sob demanda, não monitoramento
autônomo: declare frequência sugerida, entradas necessárias e o relatório a
produzir. Para release real, combine com `gate-testflight`,
`appstore-publishing` ou `playstore-publishing` e respeite as autorizações do
produto.
