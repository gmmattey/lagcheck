# Competitive Benchmark & Market Intelligence

This skill provides operational routines to track gaming network market movements, competitor features, and server infrastructure changes.

## 1. Competitor Landscape Watchlist
Track key benchmarks on mobile and desktop:
- **Direct Gaming Network Optimizers**:
  - *NoPing*: Visual benchmarks, high-contrast dark dashboard, aggressive latency tracking, gamer tone.
  - *ExitLag*: Multi-path routing concepts, real-time packet loss charts, peering partnerships.
  - *GearUP Booster*: Mobile-first UX, quick 1-tap boost buttons, visual ping comparisons before/after.
- **Speedtest / Generic Utilities (What to AVOID)**:
  - *Speedtest by Ookla / Fast.com*: Massive advertising, generic download/upload numbers, zero relevance to game engine tick rates.

## 2. Gaming Infrastructure & Routing Verification
Periodically verify endpoints and routing:
- **AWS GameLift Beacons**: Check IP ranges for `sa-east-1`, `us-east-1`, `eu-central-1` (used for Fortnite, Apex Legends).
- **Valve A2S Server Queries**: Check status of CS2 and Dota 2 official server clusters.
- **Riot Games (Valorant / LoL)**: Monitor Riot Direct peering updates and regional routing announcements.
- **Azure PlayFab QoS**: Verify beacon responsiveness for Xbox Live and multiplayer titles.

## 3. Product Parity & Innovation Checklist
- [ ] Is our test faster than competitors' startup flows?

- [ ] Are our viral Discord/WhatsApp share cards generating higher peer-to-peer engagement?
