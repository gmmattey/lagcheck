# Rascunho local Android — Nico

Esta é uma prova do pipeline de criativos para **Google Play**, feita a partir
da tela Android real de medição em repouso. A fonte foi capturada no emulador
`refrilog_capturas_api36` do APK Debug local, com anúncios desligados; não é
prova de release, de aprovação no Play Console nem de publicação.

A captura iOS em `store/app-store/pt-BR/nico-demo/` é um pacote diferente e
não pode ser reaproveitada aqui. O manifesto declara `source_platform: android`
e o validador bloqueia captura iOS neste perfil.

O rascunho não usa a Home Android porque ela inclui arte de jogo de terceiros,
que não é autorizada para criativos do LagCheck. As duas peças (screenshot e
feature graphic) mostram somente a tela de medição que a interface Android
realmente exibe.
