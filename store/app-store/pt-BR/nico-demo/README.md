# Nico — pacote demonstrativo local

Este pacote demonstra captura iOS controlada → composição → PNG final →
validação → galeria. A fonte é uma tela do binário Debug do LagCheck no
simulador com `-ui-fixture-valid-result`; ela é reproduzível, mas não prova uma
medição de rede nem valida a ficha na Apple.

As duas artes são variantes de narrativa da mesma captura. São `ready_for_review`
localmente, não aprovadas/publicadas. Antes de qualquer upload, Renan e Marco
precisam revisar fidelidade visual, copy, direitos e adequação ao build candidato.
